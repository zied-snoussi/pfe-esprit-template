# Logos

- `esprit.png` / `esprit.svg` : logo de l'école, utilisé par la page de garde (fourni).
- `entreprise.png` : logo de votre organisme d'accueil, à ajouter (PNG, fond transparent de préférence).

Tant qu'un fichier manque, la page de garde affiche un cadre à sa place.
Les logos restent la propriété de leurs titulaires : utilisez-les seulement pour vos documents de PFE.
